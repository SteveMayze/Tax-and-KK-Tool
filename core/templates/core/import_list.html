Expected CSV format

UTF-8, comma-separated, first row = column names (any order, case-insensitive). Dates as YYYY-MM-DD; amounts as plain numbers with a decimal point (1234.56, no thousands separators or currency symbols). Up to 5,000 rows and 2 MB.

Columns: {% for c in columns %}{{ c }}{% if c in required %}*{% endif %}{% if not forloop.last %}, {% endif %}{% endfor %} (* required).

  • currency: EUR, GBP, AUD or USD. frequency: monthly, quarterly, half_yearly, yearly or one_off.
  • gross_amount must be positive (corrections and reversals are entered in the app).
  • exchange_rate (optional, EUR per 1 unit of the currency): stored as a manual rate; rate_date optional. Leave empty to have the ECB rate for the payment date looked up. EUR rows never need a rate.
  • Organisations and categories are matched ignoring case; unknown names are flagged as new in the preview.
